# Fitcast Avatar Kit

핏캐스트에서 얼굴 분위기, 헤어스타일, 체형을 각각 골라 하나의 실사풍 가상 피팅 아바타로 합성하는 에셋 키트입니다.
메인 웹(`/`)의 온보딩·피팅룸에서 **여성 아바타**가 이 키트로 그려지고, 옷 레이어가 키트 몸에 맞춰 입혀집니다.

## 포함 항목

- 얼굴 6종: 강아지상, 고양이상, 햄스터상, 사슴상, 토끼상, 여우상
- 헤어 7종: 긴 생머리, 긴 웨이브, 허쉬컷, 단발, 포니테일, 숏 레이어드, 번 헤어(얼굴 자체의 묶은 머리)
- 체형 6종: 하체 중심형, 상체 중심형, 둥근 체형, 일자형, 굴곡형, 탄탄한 체형
- 실시간 레이어 합성 미리보기, 선택 결과 PNG 저장

## 실행 방법

```bash
# 키트 단독 데모 → http://localhost:8080
cd avatar_kit
python3 -m http.server 8080

# Gradio 데모 (프로젝트 루트에서)
python -m avatar_kit.gradio_demo
```

## 에셋 빌드

`assets/`는 원본(얼굴: 흰 배경 사진 `faces/`, 헤어: 누끼 PNG `hair-front/`, 체형 `bodies/`), `dist/`는 정리·정렬된 결과물입니다. 얼굴 원본은 `dist/photos/`에 손대지 않고 복사돼 랜딩 얼굴 카드에 쓰이고, `layout.photos`에 그 사진 좌표(%) 기준 헤어 배치가 들어 있습니다. 원본을 바꿨다면 다시 빌드하세요.

```bash
python avatar_kit/tools/build_assets.py
```

빌드가 하는 일:

| 대상 | 처리 |
|---|---|
| 얼굴 | 흰 배경 얼굴 사진을 누끼 → 눈 높이·머리 폭으로 정규화(가로 `FACE_SQUEEZE`·세로 `FACE_SY` 배율로 얼굴 길이를 줄임; 캔버스에 잘린 옆머리는 둥글게) → 사진의 목을 옷깃까지의 62%(`NECK_KEEP`)까지 남기고 부드럽게 끝냄. 이 목이 몸 이미지의 짧은 목 윗단을 덮어(`NECK_COVER`) 이음새가 숨고 목 길이가 살아남. 남기는 목은 행마다 실제 살색 구간만(목 옆 흰 배경 제외). 체형마다 목 밑단 높이가 달라 `bodies.<이름>.headDy`(목 밑단 기준 `NECK_BASE_REF` 대비 차이)만큼 웹이 머리를 옮겨 목 길이를 같게 맞춤. 랜딩·온보딩 카드용으로 눈이 중앙인 정사각형 구도(`crop`)도 저장 |
| 헤어 | 누끼된 헤어 PNG(모두 같은 머리 크기로 그려진 1254px)를 머리 폭 기준으로 얼굴에 맞추고, 앞머리 헤어는 앞머리 끝이 눈썹 위에, 가르마·묶은 헤어는 안쪽 가장자리가 이마 선에 오도록 배치(`HAIR_EDGE`). 원본마다 얼굴 구멍 크기가 달라 헤어별 미세 보정표 `HAIR_ADJUST`(배율·이동)를 마지막에 적용. 누끼 가장자리의 반투명 픽셀은 이미 머리색이라 배경색 제거를 하지 않음(하면 희게 뜸). 실루엣의 움푹 파인 홈(원본이 귀·목 자리로 비워둔 곳)은 모폴로지 닫힘으로 메워 `hair/<이름>-back.png` 뒷머리 레이어로 저장(포니테일은 꼬리도 여기에). 얼굴·몸 뒤에 그려져 배경이 네모나게 비치지 않음 |
| 체형 | 격자선 잔여물 제거 → 목 윗단·발바닥 기준으로 크기 통일 → 어깨선·가슴·허리·골반·가랑이·무릎·발목·팔 중심선을 측정해 옷 레이어용 골격 좌표로 저장. 회색 나시·반바지는 `bodies/<이름>-cloth.png`로 따로 저장 (피부톤 필터 제외용) |
| 헤어 컬러 | 헤어·뒷머리·얼굴 자체 머리를 `HAIR_COLORS` 7색으로 미리 물들인 `<이름>.<컬러id>.png` 저장 (웹은 SVG 필터 대신 이 파일을 씀) |

결과물 `dist/layout.json`(웹은 `dist/layout.js`)에는 레이어마다 배치 사각형(x, y, w, h)과 체형별 골격 좌표, 뒷머리 레이어(`hairBack`), 컬러 id 목록(`hairColors`)이 들어 있습니다.
좌표 단위는 `web/js/avatar.js` 골격과 같습니다 (발바닥 y=900, 몸 중심 x=0).

## 폴더 구조

```text
avatar_kit/
├── index.html · styles.css · app.js   # 키트 단독 데모 (dist/layout.js 좌표로 배치)
├── avatar_renderer.py                  # PIL 합성 (Gradio 데모·미리보기)
├── gradio_demo.py
├── preview-avatar.jpg
├── assets/                             # 원본 (faces/ · hair-front/ · bodies/)
├── dist/                               # 빌드 결과 (faces/ · hair/ · bodies/ · layout.json · layout.js)
└── tools/
    └── build_assets.py
```

## 합성 순서

1. 뒷머리 (실루엣 홈 메움·포니테일 꼬리, 몸·얼굴 뒤)
2. 체형 (목까지 포함)
3. 얼굴 (번 헤어: 얼굴 전체 / 헤어 PNG: 피부색 바탕 + 피부만 얼굴)
4. 얼굴 자체 머리 (헤어 컬러 적용, 헤어 PNG를 쓸 땐 헤어 실루엣 안에서만)
5. 헤어

웹에서는 몸과 얼굴 사이에 옷 레이어가 들어가고, 모자·안경은 헤어 위에 그려집니다.
피부톤은 몸·얼굴에 SVG 필터로 적용하고(회색 나시·반바지 레이어는 제외), 헤어 컬러는 미리 물들인 PNG를 씁니다. 헤어를 쓰면 얼굴은 ① 피부색 머리 바탕 ② 자체 머리를 뺀 `faces/<이름>-skin.png` ③ 헤어 실루엣 안에서만 보이는 자체 머리 ④ 헤어 순으로 겹칩니다. 그래서 헤어 틈으로 사진의 묶은 머리가 네모나게 비치지 않고 피부가 보입니다.

## 한계

- 얼굴 에셋이 헤어 원본이 가정한 얼굴보다 넓어서 얼굴을 가로로 보정(`FACE_SQUEEZE`)한 뒤 헤어를 볼 폭에 맞춥니다. 헤어를 쓸 때는 귀·얼굴 자체 옆머리가 헤어 밖으로 나오지 않게 볼 폭 안쪽만 그립니다 (`head.coreHalf`).
- 남성 에셋이 없어 남성 아바타는 기존 일러스트 아바타로 그립니다.
- 곰상 얼굴, 울프컷·댄디컷 등 남성 헤어는 키트에 없어 남성 선택지에서만 보입니다.
