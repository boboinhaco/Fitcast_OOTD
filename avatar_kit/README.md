# Fitcast Avatar Kit

핏캐스트에서 얼굴 분위기, 헤어스타일, 체형을 각각 골라 하나의 실사풍 가상 피팅 아바타로 합성하는 에셋 키트입니다.
메인 웹(`/`)의 온보딩·피팅룸에서 **여성 아바타**가 이 키트로 그려지고, 옷 레이어가 키트 몸에 맞춰 입혀집니다.

## 포함 항목

- 얼굴 6종: 강아지상, 고양이상, 햄스터상, 사슴상, 토끼상, 여우상
- 헤어 7종: 긴 생머리, 긴 웨이브, 허쉬컷, 단발, 포니테일, 숏 레이어드, 번 헤어(얼굴 자체의 묶은 머리)
- 체형 6종: 하체 중심형, 상체 중심형, 둥근 체형, 일자형, 굴곡형, 탄탄한 체형
- 실시간 레이어 합성 미리보기, 선택 결과 PNG 저장

## 실행 방법

```bash
# 키트 단독 데모 → http://localhost:8080
cd avatar_kit
python3 -m http.server 8080

# Gradio 데모 (프로젝트 루트에서)
python -m avatar_kit.gradio_demo
```

## 에셋 빌드

`assets/`는 원본, `dist/`는 정리·정렬된 결과물입니다. 원본을 바꿨다면 다시 빌드하세요.

```bash
python avatar_kit/tools/build_assets.py
```

빌드가 하는 일:

| 대상 | 처리 |
|---|---|
| 얼굴 | 투명 영역 밑에 남아 있던 원본 픽셀로 머리·귀까지 다시 누끼 → 눈 높이·머리 폭으로 정규화 → 넓적한 원본을 가로로만 줄여 갸름한 비율로 보정(`FACE_SQUEEZE`)하고 캔버스에 잘린 옆머리를 둥글게 다듬음 → 턱선 아래(원본의 사각형 목)를 잘라내 몸 이미지의 목과 이어지게 함. 정수리가 잘린 얼굴은 기준 얼굴의 정수리로 채움 |
| 헤어 | 예전 빌드가 얼굴 자리를 타원으로 지워 사라졌던 앞머리를 복구 → 그 타원의 폭이 기준 얼굴의 볼 폭에 맞도록 배율을 정하고, 앞머리 헤어는 앞머리 끝이 눈썹 위에, 가르마·묶은 헤어는 안쪽 가장자리가 이마 선에 오도록 배치 (`HAIR_EDGE`). 긴 생머리·긴 웨이브는 옆머리가 얼굴을 덮지 않게 얼굴 윤곽을 따라 얼굴 자리를 열어 줌 (`HAIR_CARVE`). 포니테일 꼬리는 `hair/ponytail-back.png` 뒷머리 레이어로 분리 |
| 체형 | 격자선 잔여물 제거 → 목 윗단·발바닥 기준으로 크기 통일 → 어깨선·가슴·허리·골반·가랑이·무릎·발목·팔 중심선을 측정해 옷 레이어용 골격 좌표로 저장. 회색 나시·반바지는 `bodies/<이름>-cloth.png`로 따로 저장 (피부톤 필터 제외용) |
| 헤어 컬러 | 헤어·뒷머리·얼굴 자체 머리를 `HAIR_COLORS` 7색으로 미리 물들인 `<이름>.<컬러id>.png` 저장 (웹은 SVG 필터 대신 이 파일을 씀) |

결과물 `dist/layout.json`(웹은 `dist/layout.js`)에는 레이어마다 배치 사각형(x, y, w, h)과 체형별 골격 좌표, 뒷머리 레이어(`hairBack`), 컬러 id 목록(`hairColors`)이 들어 있습니다.
좌표 단위는 `web/js/avatar.js` 골격과 같습니다 (발바닥 y=900, 몸 중심 x=0).

## 폴더 구조

```text
avatar_kit/
├── index.html · styles.css · app.js   # 키트 단독 데모 (dist/layout.js 좌표로 배치)
├── avatar_renderer.py                  # PIL 합성 (Gradio 데모·미리보기)
├── gradio_demo.py
├── preview-avatar.jpg
├── assets/                             # 원본 (faces/ · hair-front/ · bodies/)
├── dist/                               # 빌드 결과 (faces/ · hair/ · bodies/ · layout.json · layout.js)
└── tools/
    └── build_assets.py
```

## 합성 순서

1. 뒷머리 (포니테일 꼬리, 몸·얼굴 뒤)
2. 체형 (목까지 포함)
3. 얼굴 (턱선까지)
4. 얼굴 자체 머리 (헤어 컬러 필터 대상)
5. 헤어

웹에서는 몸과 얼굴 사이에 옷 레이어가 들어가고, 모자·안경은 헤어 위에 그려집니다.
피부톤은 몸·얼굴에 SVG 필터로 적용하고(회색 나시·반바지 레이어는 제외), 헤어 컬러는 미리 물들인 PNG를 씁니다.

## 한계

- 얼굴 에셋이 헤어 원본이 가정한 얼굴보다 넓어서 얼굴을 가로로 보정(`FACE_SQUEEZE`)한 뒤 헤어를 볼 폭에 맞춥니다. 헤어를 쓸 때는 귀·얼굴 자체 옆머리가 헤어 밖으로 나오지 않게 볼 폭 안쪽만 그립니다 (`head.coreHalf`).
- 남성 에셋이 없어 남성 아바타는 기존 일러스트 아바타로 그립니다.
- 곰상 얼굴, 울프컷·댄디컷 등 남성 헤어는 키트에 없어 남성 선택지에서만 보입니다.
